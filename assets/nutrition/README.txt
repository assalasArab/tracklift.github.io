Dessins du questionnaire Nutrition
==================================

Format : PNG à fond transparent, style dessiné (comme la cloche de l'appli Goomy).
Illustrations d'étape : environ 600 x 440 px (affichées jusqu'à 220 px de haut).
Icônes de choix : 256 x 256 px (affichées en 56 px).

Une fois le PNG déposé ici, ajouter son nom dans ILLU_READY (js/nutrition.js).
Tant qu'un nom n'y figure pas, l'emplacement reste masqué.
