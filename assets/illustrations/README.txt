Dessins de TrackLift
====================

Format : PNG à fond transparent, style dessiné (comme la cloche de l'appli Goomy).
- Illustrations d'écran : environ 600 x 440 px.
- Icônes de choix : 256 x 256 px.

Une fois un PNG déposé ici, ajouter son nom dans ILLU_READY (js/illustrations.js).
Tant qu'un nom n'y figure pas, son emplacement reste masqué.
